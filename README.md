# Quotes Weekly Top Bot

Бот для еженедельного подсчёта реакций на цитатах в Telegram-канале
и публикации топа авторов и самой популярной цитаты.

## Как это работает

Проект состоит из двух частей:

1. **`script.py`** — юзербот на Telethon. Работает от имени вашего
   аккаунта, читает историю канала за последние N дней, считает реакции,
   парсит авторов из цитат и сохраняет отчёт в `reports/report_*.json`.
2. **`bot.py`** — бот на pyTelegramBotAPI. По команде `/report` запускает
   `script.py` как подпроцесс, дожидается завершения, читает свежий JSON
   и публикует отчёт в канал.

Разделение нужно потому, что **обычный бот не видит реакции** на посты
в каналах — доступ к ним есть только у пользовательских клиентов.

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/your_username/quotes-bot.git
cd quotes-bot
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Создать `.env`

Скопируйте `.env.example` в `.env` и заполните:

```env
API_ID=1234567
API_HASH=your_api_hash
BOT_TOKEN=123456:ABC-DEF...
```

- `API_ID` и `API_HASH` — с https://my.telegram.org/apps
- `BOT_TOKEN` — от [@BotFather](https://t.me/BotFather)

- `CHANNEL_INFO` — канал, откуда собираются цитаты. (юзернейм канала)
- `CHANNEL_SEND` — канал, куда публикуется отчёт (бот должен быть админом). (юзернейм канала)
- `DAYS` — за сколько последних дней считать.

### 5. Первый запуск

При первом запуске `script.py` попросит номер телефона и код
подтверждения — создастся файл `session.session`. Храните его в тайне,
не коммитьте.

## Использование

Запустите бота:

```bash
python bot.py
```

В Telegram отправьте боту `/report`. Он запустит сбор данных и
опубликует результат в `CHANNEL_SEND`.

### Команды

- `/start` — приветствие
- `/report` — собрать и опубликовать отчёт
- `/help` — справка

## Структура отчёта

`reports/report_YYYY-MM-DD_HH-MM-SS.json`:

```json
{
  "quotes": [...],
  "top_authors": [...],
  "top_quotes": [...],
  "top_quote": {...},
  "summary": {...}
}
```

## Безопасность

- **Не коммитьте** `.env` и `*.session` — они в `.gitignore`.
- Юзербот работает от вашего аккаунта. Используйте **отдельный аккаунт**,
  не основной.
- Бот должен быть **администратором** `CHANNEL_SEND` с правом публикации.
